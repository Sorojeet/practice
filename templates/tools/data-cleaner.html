How the Data Cleaner works

  1. Upload an Excel or CSV file and pick the sheet.
  2. Add steps: trim spaces, remove duplicates and empty rows, fix text case, fill missing values, find and replace, convert types or tidy column names.
  3. Apply the steps, read what changed in each step, and download the cleaned file as xlsx or csv.

Files are processed in memory and are not stored. Sheets up to {{ "{:,}".format(max_rows) }} rows are supported on the default settings.
