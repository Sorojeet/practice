Compare Files

Find what changed between two spreadsheets. See added, removed and changed rows, with every changed cell shown as old and new value.

How should rows be matched?

Key columns (an ID that identifies a row). Leave empty to match row 1 with row 1, row 2 with row 2, and so on.
Columns to ignore

Differences

    How Compare Files works

    1. Upload the original file as A and the new version as B.
    2. Choose key columns such as an ID, or compare by row position.
    3. Review added, removed and changed rows, then download an Excel report with a summary and one sheet per difference type.

    Numbers are compared as numbers, so 1 and 1.0 match. Only columns with the same name in both files are compared.
