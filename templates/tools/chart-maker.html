How the Chart Maker works

  1. Upload an Excel or CSV file and pick the sheet.
  2. Choose a chart type, the X column and the value columns. Add a series column to split values into groups.
  3. Download the finished chart as PNG or SVG, or export the chart data as csv.

Date columns can be grouped by year, quarter, month or day. Large tables are summarised on the server, so the chart stays fast.
